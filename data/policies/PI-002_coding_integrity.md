# PI-002 Coding Integrity: Upcoding and Unbundling

## 1. Scope

Applies to professional claims using evaluation and management (E/M) codes
and laboratory panel codes. Facility and vendor invoices are governed by
Policy PI-003.

## 2. Upcoding Indicators

An E/M claim is an upcoding indicator when any of the following hold:

- the billed amount exceeds the peer median for the same procedure code by a
  robust z-score of 4 or more, as computed by the payment integrity model;
- a primary-care provider bills level 5 visits (99215) for more than 15 percent
  of visits in a rolling quarter;
- the provider has a prior confirmed upcoding case within 24 months.

A single indicator is a medium-severity finding. Two or more indicators, or
one indicator with a prior confirmed case, is a high-severity finding and
requires investigator review before any provider outreach.

## 3. Unbundling

Billing the component codes of a panel separately on the same service date
for the same member and provider, when a bundled panel code exists, is
unbundling. Recognized panel pairs are listed in Appendix A. Unbundling is a
medium-severity finding; the disposition is a repricing to the bundled code
and an education letter unless a prior confirmed case exists.

## 4. Required Evidence

The case summary must cite the claim identifiers for every component claim
and the peer baseline used. A finding without cited claim identifiers is
incomplete and must not be escalated.

## Appendix A. Recognized Panel Pairs

| Components      | Bundled code |
|-----------------|--------------|
| 80053 + 85025   | 80050        |
| 80048 + 80061   | 80053 (partial) |
